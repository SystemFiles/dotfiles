# skills-registry.txt
# =============================================================================
# Declarative registry of AI skills installed by the `skills` CLI on every
# `chezmoi apply` (see .chezmoiscripts/run_install-skills.sh.tmpl).
#
# This file is NOT deployed to the home directory (see .chezmoiignore). It is
# read at render time via {{ include "skills-registry.txt" }}.
#
# Grammar (one entry per line):
#   <source> [version=REF] [skill=NAME] [agents=a,b]
#
#   - Lines beginning with `#` and blank lines are ignored.
#   - <source>   : first token. GitHub shorthand `owner/repo`, a full git URL,
#                  or a `/tree/<ref>/...` URL.
#   - version=   : optional git ref to pin. Resolved to
#                  https://github.com/<owner>/<repo>/tree/<ref> for shorthand /
#                  GitHub URL sources (the `skills` CLI has no --version flag).
#   - skill=     : optional single skill name within the source. Omit for all.
#   - agents=    : optional comma-separated agents. Default: cursor,claude-code.
#
# Skills install in symlink mode (canonical copy in ~/.agents/skills/<skill>,
# symlinked into each agent's skills dir). Pin third-party sources with version=
# to avoid silently pulling changed upstream content.
# =============================================================================
